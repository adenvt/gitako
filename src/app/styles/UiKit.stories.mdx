# UI Kit

The shared control kit lives in `src/shared/components/ui/`. Each control
is a className-injecting wrapper over a **Base UI** primitive, applying one
of the `ui-*` classes from `base.css`. Use these instead of raw HTML so the
control chrome stays consistent app-wide.

## Buttons

`.ui-btn` (default "solid"), `.ui-btn-primary` (accent fill), `.ui-ghost` (borderless), or `<Button variant="none">` (caller-styled).

<Canvas of={ButtonStories.AllVariants} />

## Inputs

Use `<Input>` from `@/shared/components/ui`. Defaults to `size="md"`.

**Sizes:** `sm` (dense, `--fs-sm`), `md` (default), `lg` (emphasis, `--fs-lg`).

**State** (`loading` | `success` | `invalid`): mutually exclusive, single prop.
`loading` disables the input and renders a trailing spinner; `success` shows a
green check; `invalid` shows a red alert icon, applies a red border, and sets
`aria-invalid="true"`.

**Affixes:** `prepend` and `append` accept `ReactNode` and render in the same
flex shell as the input. The shell carries the border; the input inside is
borderless so the affix sits flush. Affix content has `pointer-events: none` —
clicks pass through to the input.

**Clearable:** when `clearable` and the value is non-empty (and not
loading/disabled), renders a `×` button. Clicking fires `onChange` with an
empty value so controlled-input consumers see the change.

## Textareas

Use `<Textarea>` from `@/shared/components/ui`. Matches `<Input>` for sizing
and `state="invalid"`. **No `loading`/`success` state** (no real estate for a
trailing icon — select-all + delete is the multi-line equivalent).

**Clearable:** when `clearable` and the value is non-empty, renders a `×`
button top-right.

## Comboboxes

Two anatomies — `variant="trigger"` (bare caret, used by `BranchSwitcher`) or
`variant="input"` (bordered input + caret shell, used by `AiSettingsPage`).
The trigger inside the input-group shell gets its chrome from the descendant
rule `.ui-input-group > button` in `base.css`.

## ScrollArea

`.ui-scrollarea` for the root, plus custom `.scrollbarTrack` / `.scrollbarThumb`
chrome that matches the TUI palette. Use `<ScrollArea>{content}</ScrollArea>` for
the common case, or `<ScrollArea.Root>…</ScrollArea.Root>` for advanced cases
(custom scrollbar children, viewport measurement).
