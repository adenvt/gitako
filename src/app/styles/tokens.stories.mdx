# Design Tokens

The app's visual system is defined by CSS custom properties in `src/app/styles/base.css`.
There is one accent color (green), one radius scale (0px; TUI aesthetic), and one font
(IoskeleyMono — used for both UI and code via `--font-ui` / `--font-mono`).

## Surfaces

| Token              | Value     | Role                              |
| ------------------ | --------- | --------------------------------- |
| `--bg`             | `#0f1319` | Terminal ground (window)          |
| `--bg-raised`      | `#161b23` | Panels, toolbar, inputs           |
| `--bg-hover`       | `#1d242e` | Row/button hover                  |
| `--bg-active`      | `#222b36` | Pressed                           |
| `--bg-inset`       | `#0b0e13` | Wells, scrollbar track            |
| `--bg-selected`    | `#1f3324` | Selected row (green-tinted)       |
| `--border`         | `#2a323e` | Hairline                          |
| `--border-strong`  | `#3a4452` | Popups, toasts                    |

## Text

| Token         | Value     | Role       |
| ------------- | --------- | ---------- |
| `--text`      | `#d6dde6` | Default    |
| `--text-dim`  | `#7e8a99` | Muted      |
| `--text-faint`| `#525a66` | Very muted |

## Accents

| Token             | Value     | Role                          |
| ----------------- | --------- | ----------------------------- |
| `--ok`            | `#7ec07c` | Success / green accent         |
| `--err`           | `#e06c75` | Error                          |
| `--warn`          | `#e5c07b` | Warning                        |
| `--info`          | `#61afef` | Info                           |
| `--accent`        | `#7ec07c` | == `--ok` — single accent      |
| `--accent-strong` | `#9ed09c` | Hover/active accent            |
| `--accent-dim`    | `#1f3324` | == `--bg-selected`            |
| `--accent-border` | `#4a7a4c` | Focused-input border           |
| `--on-accent`     | `#0f1319` | Text on accent fill            |

## Radius

| Token         | Value | Note                          |
| ------------- | ----- | ----------------------------- |
| `--radius`    | `0`   | TUI = no rounding             |
| `--radius-s`  | `0`   | Legacy alias                  |
| `--radius-m`  | `0`   | Legacy alias                  |
| `--radius-l`  | `0`   | Legacy alias                  |

## Spacing

`--space-1: 4px` · `--space-2: 8px` · `--space-3: 12px` · `--space-4: 16px` · `--space-5: 24px` · `--space-6: 32px`

## Fonts

`--font-ui`, `--font-mono` = **IoskeleyMono** (self-hosted WOFF2, regular weights).
`--font-display` = **IoskeleyMono SC** (SemiCondensed, used for uppercase section labels).

## Type scale

`--fs-xs: 12px` · `--fs-sm: 13px` · `--fs-md: 14px` · `--fs-lg: 15px` · `--fs-xl: 17px`

## Motion

`--ease: cubic-bezier(0.2, 0, 0, 1)` · `--dur-fast: 80ms` · `--dur-med: 120ms`

## Effects

`--overlay-shadow: none` — the design has no shadows ("TUI" aesthetic).

## Known duplication (to be consolidated)

- `--accent` / `--ok` / `LANE_COLORS[0]` all share `#7ec07c`.
- `--bg-selected` / `--accent-dim` / `--selected` all share `#1f3324`.
- `--overlay-shadow` is declared but never used; banned by convention.
